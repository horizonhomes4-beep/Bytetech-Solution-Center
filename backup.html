Important: The Excel file is designed for people to read. Information is separated into normal columns instead of being hidden inside technical JSON text. The JSON file is also downloaded because it preserves the exact Firebase database structure and is useful for restoring the database.

How this backup works

1. The page continuously reads the current Teachers, Students and Teacher Payments data.

2. Click Create Excel Backup whenever you want to save a backup.

3. The Excel file automatically separates information into readable columns such as Teacher Name, Phone Number, Email, Payment Date and Amount.

4. The filename automatically contains the date and time, for example: lesson-payment-backup-2026-09-25-141300.xlsx

5. An exact JSON backup with the same timestamp is downloaded at the same time.
